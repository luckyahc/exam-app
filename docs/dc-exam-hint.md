# 데이터 통신 시험 힌트 · 힌트관련1~5 모의시험

작성: 2026-10-22. 교수님이 공지한 중간고사 힌트(사용자 제공)와, 그 힌트대로 만든 모의시험 세트 5개(`data/subjects/data-comm/hintExams.ts`)의 구성을 적는다.

## 1. 시험 힌트(원문 요약)

- **출제 범위**: 1장(Introduction) ~ 2장(Physical Layer) 수업 내용 전체에서 골고루
- **문항·배점**: 총 23~26문제, 30점 — 선택형 1점/문제, 주관식 2~4점/문제
- **계산**: 계산 문제가 있지만 복잡하지 않아 공학용 계산기가 필요 없다
- **표·그림**: 문제에 표나 그림이 들어갈 수 있다
- **방식**: 사이버 캠퍼스 온라인 시험. 한 화면에 한 문제, 왼쪽 문제 번호로 돌아가 다시 풀 수 있다
- **선택형**: 5지선다. '모두 고르시오'로 끝나는 문제는 정답 2~4개, **부분 점수 없음**
- **섞기**: 문제 순서와 보기 순서가 학생마다 무작위

## 2. 앱에 반영한 것

| 힌트 | 반영 |
|---|---|
| 23~26문제 | 세트마다 **25문항** |
| 선택형 1점 · 주관식 2~4점 = 30점 | 선택형 21(mcq 16 + multi 5) + 주관식 4(용어 단답형 — "다음 설명에 해당하는 용어를 쓰시오", 설명 → 칸 하나. OS 단답형과 같은 모양. 계산 문제로 채우지 않는다, 2026-10-23) → 21 + 2 + 2 + 2 + 3 = 30점이 되는 구성. 앱의 점수는 문항 수 기준이라 배점은 따로 매기지 않는다 |
| 5지선다 | 세트의 mcq·multi 보기는 모두 5개 |
| '모두 고르시오' 정답 2~4개, 부분 점수 없음 | multi 정답 2·3·4개를 섞어 냈고, 데이터 통신 과목의 multi를 0/1 채점으로 바꿨다(`allOrNothing: ["multi"]` — 기존 데이터 통신 multi 문항에도 적용) |
| 계산(계산기 불필요) | 계산형 객관식의 정답은 손으로 구할 수 있는 값이다. log₂는 2의 거듭제곱(또는 log₂ 1001 ≈ 10처럼 근삿값을 지문에 줌), √2는 1.41로 준다. 2026-10-22 손으로 풀기 어렵던 3문항(비트 길이 1/720,000, log₂ 1001, 110 × √2)을 고쳤다. 정답은 `lib/sim/data-comm` 함수로 구하고 `hintExams.test.ts`가 다시 계산한다. **비중**: 힌트에 계산 문제 수는 없고 '복잡하지 않다'고만 해서 세트당 계산형 객관식 3문항으로 둔다 — 2026-10-23 계산형 객관식 22문항(세트당 7~8 → 3)을 같은 소주제의 개념 문항으로 바꿨고, 같은 날 주관식 20문항(계산 15 + 문장 빈칸 5)을 모두 같은 소주제의 용어 단답형으로 바꿨다(사용자: "계산문제로 주관식을 떼우지마", "내가 말하는 주관식은 용어") |
| 표·그림 | 세트마다 표 문항 1개(```text 블록). 화면에 없는 슬라이드 그림은 가리키지 않는다(`noFigureRefs.test.ts`) |
| 문제·보기 무작위 | 과목 홈 '힌트관련N 풀기'는 문제 순서를 섞고(족보관련1·2와 달리 고정 순서 아님), 보기는 문항마다 섞는다 |
| 한 문제씩·문제 번호로 이동 | 기본 채점 방식 = 시험 모드, 기본 화면 = 실제 시험 화면(e-Class) |
| 시험 시간 | 제한 시간을 고른다(10·20·30·60분 또는 **직접 입력 1~300분**) |
| 난이도 | 중간(2)·어려움(3)만, 세트마다 어려움 10문항 이상 |

- **힌트관련4·5는 더 헷갈리게**(2026-10-22 사용자 요청): 오답을 정답에서 한 군데만 바꾼 문장(뒤바뀐 짝·방향), 단위 변환(바이트↔비트, ms·μs·nW), 비슷한 공식(10 log vs 20 log, Nyquist vs Shannon, 2Δf, FM β vs PM β), 계산 한 단계를 빠뜨린 값(1을 더하지 않은 17.9 kbps 등), 풀이에 필요 없는 수치를 섞었다. 난이도는 대부분 어려움(세트마다 20문항 이상).
- **id**: `data-comm-{ch01|ch02}-hint{세트}-{세트 안 번호 001~025}` — 분류 `hint1`~`hint3`(`lib/quiz/jokbo.ts`), 뱃지 "힌트관련N", "일반" 분류에도 들어간다.
- **해설**: `s.번호 (p.쪽):`으로 시작하고 근거 슬라이드 원문 + 함정(오답이 나오는 계산 실수·혼동)을 적는다. 슬라이드에 없는 내용은 "(보충)"으로 표시한다(예: dB를 구간마다 더하기 `hint1-015`, 매체가 바뀌어도 주파수는 그대로 `hint4-012`, FM·PM의 β가 다를 수 있음 `hint5-023`).

## 4. 함께 정리한 것

- **연도 문제 삭제**(2026-10-22 사용자 요청): `data-comm-ch01-osi-003`(OSI 소개 시기 1970년대 후반), `data-comm-ch01-osi-004`(ISO 설립 1947년). Ch01 최소 문항 수 57 → 56, OSI 소주제 목표 3 → 2(`docs/coverage-matrix.md`, `docs/verification/data-comm-ch01-ch02.md`). 힌트관련 세트에도 연도 문제는 없다(`hintExams.test.ts`가 확인).
