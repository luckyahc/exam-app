# 운영체제 기말 출제 형식 (족보: source/os/jokbo_update, e-Class 중간시험 화면 17장 · 답안지 16~46번 31문항)

- 유형 비율(16~46번): 복수 선택 12 (39%, "[두 가지]·[두 개] 고르시오") · 단답 9 (29%, 숫자열·용어) · 단일 선택 6 (19%) · 짝 짓기 4 (13%, `[1] → A` 꼴).
- 대괄호 강조: 지문의 핵심 조건을 [ ]로 감싼다 — "[없는] [두 가지]를 고르시오", "[틀린] 것을 [두 개] 고르시오", "[잘못된 두 개]".
- 보기 5개(복수 선택은 정답 2개가 기본). 보기는 완결된 문장.
- 단답: 여러 값을 한 칸에 "공백없이" 이어 쓰게 한다(예: "네 개의 숫자를 공백없이 기술할 것, 예] 241001"), 용어는 지정한 표기(영어·대문자).
- 그림·표는 글자로: `[0] 0* + <--` 같은 ASCII 그림, 공백 정렬 표(```text 블록). 지문 → 그림 → 조건 → "(단, …)" 순서.
- 이 앱에서: multi(정답 2개, 보기 5) > blank(숫자열·용어) > mcq(보기 5) > match. ASCII 그림은 jokboSource.ts의 block(). 근거는 Ch11 강의자료(45쪽)뿐, 없는 설명은 "(보충)".
- ⭐ handwritten: 강의자료 필기 "시험" 표시 쪽(p.4, p.12, p.16, p.21, p.22, p.25, p.36, p.38, p.42). p.7(X 표시)은 출제 제외, p.35(참고)는 출제하지 않음.
