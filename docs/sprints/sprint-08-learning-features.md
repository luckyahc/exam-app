## 이 문서와 다르게 한 부분

1. **⭐ 달성도 정의**: 예시("⭐ 문제 중 완전히 맞춘 비율")를 "⭐ 문제 중 **마지막 풀이가** 완전히 맞은 비율"로 정했다. 한 번 맞히고 이후 틀린 문제를 달성으로 세지 않기 위해서다. 화면에 정의를 적어 두었다.
2. **가져오기 방식 선택 단위**: "과목별 덮어쓰기/합치기 선택" 대신 파일 하나에 방식 하나(다이얼로그에서 합치기/덮어쓰기)를 고른다. 과목별 범위는 내보내기에서 과목을 골라 맞출 수 있고, 지금은 기록이 있는 과목이 OS 하나뿐이라 UI를 단순하게 했다. 필요하면 과목별 선택으로 늘린다.
3. **비슷한 문제 버튼 위치**: 즉시 채점에서 채점을 마친 생성기 문제에만 보인다(시험 모드에서는 문제 수가 바뀌므로 숨김). 새 문제는 지금 문제 바로 다음에 끼워 넣고, `SessionItem.gen`을 남겨 새로고침해도 다시 만든다. 새 seed는 1,000,000 이상이라 데이터 문항 id와 겹치지 않아 기록이 섞이지 않고, 대시보드는 생성 문제 풀이를 따로 표시한다.
4. **추가**: 오답노트가 문제 데이터에 없는 생성기 오답도 기록의 생성기 정보로 다시 만들어 보여 준다(이전에는 목록에서 빠졌음).
