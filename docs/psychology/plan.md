- 범위: PDF 하단 쪽 번호 2~28 = PDF 1~29페이지(표지 때문에 하단 번호 = PDF 페이지 − 1). CHAPTER 01~08. CHAPTER 09 사고와 언어(하단 p.29)부터는 쓰지 않는다.

## 0. 구조

- 단원 8개 `c01`~`c08`, 이름·순서는 PDF 목차(교재 판 표기: Ch03 "의식과 이중 처리과정"). 옛 단원 id(`ch01`~`ch07`)와 겹치지 않으므로 브라우저에 남은 옛 문항 기록(`psychology-ch01-…`)은 어디에도 잡히지 않는다 — 통계·오답노트·북마크·세션 불러오기에서 조용히 빠진다(`psychology.test.ts`가 검사). 대시보드의 "생성 문제" 집계는 id에 `-gen-`이 있는 기록만 센다(`lib/stats.ts generatedAttempts`).
- 문항 id: `psychology-c0N-{case|compare|link|order|short|essay}-NNN`.
- 문항 타입·기능은 그대로: 객관식 mcq/multi/ox/match/order, 단답형 = blank 한 칸(`답: {{0}}`, 인정 답안 여러 개), 서술형 = essay(자기 채점, "제출함"), 해설 끝 "근거:" 한 줄.
- 근거 목록(소제목·표·굵은 용어·학자): `data/subjects/psychology/terms.ts`. 굵은 용어는 PDF의 빨간 굵은 글씨를 pdftohtml 글꼴 정보로 뽑았다.

## 1. 근거 규칙

- PDF는 pdftotext로 한 번 추출하고 이후 grep. 표가 깨진 곳은 pdftoppm으로 렌더링해서 확인(하단 p.3의 손글씨 메모 "후견 편향", "과신").
- **용어 표기는 교재 판 PDF가 최우선**(2026-10-23 사용자 지시). 문제·보기·정답은 교재 표기(예: 간상체·원추체, 청크 만들기, 파블로프식 조건형성, 도약대, 진행성 기억상실증). 요약 노트 표기(막대세포·원뿔세포, 청킹, 고전적 조건형성, 비계, 순행성 기억상실증)는 해설 괄호("요약 노트 표기 …")와 단답형 인정 답안에만 둔다.
  - 교재 판 PDF의 치환 오류는 따르지 않는다: "내분비계"가 "내분도약대"로 바뀐 곳(비계 → 도약대가 단어 안까지 치환) → **내분비계** 유지. Ch04 진화심리학 비판의 "사후 설명"(결과를 보고 만든 설명)은 연구 윤리의 "사후 설명 → 실험 후 설명"과 다른 말이라 그대로 둔다(교재 판도 그대로).
- 쪽 번호는 원본 `summary-notes.pdf`의 하단 쪽 번호로 쓴다: 해설 끝 `근거: PDF p.X`(범위는 `p.X-Y`), slideRef `Ch0N p.X`.
- PDF에 없는 내용(연구자, 수치, 예시, 기제)을 해설에 쓰면 `근거: PDF p.X + 보충`. PDF에 없는 수치·연도를 정답 근거로 쓰지 않는다. 문항 안의 가상 사례(인물·장면)는 문제 장치라 보충으로 세지 않는다.
- PDF 서술이 표준 심리학과 명백히 다른 지점으로는 문항을 만들지 않고 목록만 남긴다:
  - 간상체와 원추체 표의 원추체 "위치: 중심와 주변" — 표준은 중심와(망막 중심)에 밀집. 같은 PDF의 눈 구조 표("중심와: 원추체가 밀집한 망막 중심")와도 어긋나 이 칸은 쓰지 않았다.
  - 꿈 이론 표의 정보 처리 이론 비판 "태아도 REM 수면을 함" — 교재의 일반적 비판은 영아(기억할 일이 적은 시기)의 많은 REM. 비판 내용으로 문항을 만들지 않았다(해설에서도 일반화해 씀).
  - 약물 분류 표에서 엑스터시를 환각제로만 둔 것 — 교재는 흥분제이자 약한 환각제. 엑스터시의 분류를 정답으로 묻지 않았다.

## 2. 문항 구성 (200문항)

- 장별 수량(PDF 분량 비례): 01 26 / 02 28 / 03 22 / 04 22 / 05 24 / 06 28 / 07 26 / 08 24.
- 유형 비율: 객관식 50%(100) / 단답형 30%(60) / 서술형 20%(40). 장마다 ±3%p.
- 객관식 안에서: 사례 적용(case) > 비교·구분(compare) > 학자·이론·실험 연결(link) > 순서·단계(order), 장마다 이 순서로 많다.
- PDF의 ■ 비교표 32개(01 학파의 흐름·분석 수준별 관점·기술적 방법·연구 방법 비교 / 02 뉴런의 구조·신경전달물질·뇌 연구 도구·뇌간·대뇌피질 / 03 수면 단계·수면 장애·꿈 이론·약물 분류 / 04 개인주의와 집단주의 / 05 발달 쟁점·피아제·애착 유형·양육 방식·콜버그·에릭슨 / 06 역치·눈의 구조·간상체와 원추체·깊이 지각 / 07 파블로프 용어·조건형성 과정·강화와 처벌·강화계획·두 조건형성 비교 / 08 앳킨슨-쉬프린·외현기억과 암묵기억·망각 원인)는 표마다 2문항 이상, 모두 ⭐. 기억상실증은 PDF에서 표가 아니라 목록이라 표로 세지 않는다.
- PDF의 모든 ■ 소제목은 문항 topic으로 1회 이상, 모든 굵은 용어·학자 이름은 문제·보기에 1회 이상. 결과는 [`coverage.md`](./coverage.md)(테스트가 데이터와 같은지 검사, 누락 0).
- 학자·실험(분트·제임스·왓슨·스키너·파블로프·손다이크·톨만·가르시아·반두라·피아제·비고츠키·에릭슨·콜버그·하이트·할로·로렌츠·에인스워스·허블과 비젤·깁슨과 워크·에빙하우스·배들리·로프터스와 파머·H.M. 등)은 이름과 핵심 주장·실험을 잇는 문항(주로 link의 match)에 넣었다.
- 서술형은 맥락형(사례를 이론으로 설명, 두 개념 비교, 연구 설계의 문제점, 망각 원인 분석). modelAnswer 3~6문장 + keyPoints 3~5개.
- 단답형 정답은 1~3단어로 하나로 확정되는 것만. 인정 답안: 교재 표기 → 요약 노트 표기 → 흔한 다른 표기 → 영문. 문제 글에 정답 표기를 넣지 않는다(테스트).
- 해설: `why(정답 이유, 오답이 틀린 이유, 같은 장의 관련 개념 1줄, 근거)`(`helpers.ts`) — "정답: … 오답: … 연결: …\n근거: PDF p.X".
- examBasis: PDF 표·굵은 용어에서 나온 문항은 printed-emphasis(⭐, summary 필수). 표 문항과 단답형은 모두 ⭐. 그 밖의 사례·비교·서술형은 `exam: false`.

## 4. 토큰 절약 규칙

- PDF는 처음 한 번만 추출하고 이후 grep. 관련 없는 과목 폴더는 열지 않는다.
- 문항은 장별 파일에 바로 쓰고 채팅에 다시 출력하지 않는다(검증은 테스트로).
- 전체 테스트(`npm test -- --maxWorkers=1`)·타입체크·빌드는 마지막에 1회, 실패한 것만 다시 실행. 브라우저·dev 서버는 쓰지 않는다.
