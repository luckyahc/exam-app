[1] 임의의 숫자를 찾기 위한 순차 탐색의 평균 경우 시간복잡도를 구하시오. 단, n개의 숫자가 있다고 가정하자.
[답] 찾고자하는 숫자가 배열의 각 원소에 있을 확률이 동일하다고 가정하고, 즉, 1/n, 기대 비교회수를 구하면
1회 비교 후 찾은 경우 1x1/n
2회 비교 후 찾은 경우 2x1/n
⋯
n 비교 후 찾은 경우 nx1/n
기대 비교 회수 = 1/n[1+2+⋯+n] = (n+1)/2 = O(n)
[2] 4장의 작업 스케줄링 문제는 n개의 작업을 모두 수행시키는데 필요한 기계의 수를 최적화하는 문제이다. 그러나 이 문제를 변형하여, 기계가 1대만 있고, n개의 작업들이 있을 때 가장 많은 수의 작업들을 수행시키고자 한다. 이 문제를 해결하기 위한 그리디 알고리즘을 설계하시오. 
[답]
작업들을 종료시간으로 정렬하여 차례로 배정한다. 즉, 가장 이른 종료시간 우선 (earliest finish time first) 원칙으로 배정하면 된다.
[3] 5장 배낭문제에서 아래의 표를 참조하여 K[3,10]이 왜 70인지를 설명하시오.

[답] K[3,10] 
= max{ K[i-1,w], K[i-1,w-wi]+vi } 
= max{ K[3-1,10], K[3-1,10-6] +30} 
= max{ K[2,10], K[2,4]+30} 
= max{ 50, 40+30} = max{50,70} = 70이다. 즉, K[3,10]=70이다.

[5] 1로 만들기
정수 X에 사용할 수 있는 연산은 다음과 같이 세 가지 이다.
X가 3으로 나누어 떨어지면, 3으로 나눈다.
X가 2로 나누어 떨어지면, 2로 나눈다.

정수 N이 주어졌을 때, 위와 같은 연산 세 개를 적절히 사용해서 1을 만들려고 한다. 연산을 사용하는 횟수의 최솟값을 출력 하시오.
[입력] 첫째 줄에 1보다 크거나 같고, 106보다 작거나 같은 정수 N이 주어진다.
[출력] 첫째 줄에 연산을 하는 횟수의 최솟값을 출력한다.
