- 검증 파이프라인 보강(문항을 쓰다 필요해짐): Colab 셀 표시 검증 `check.cell`(Lec1 s.20), 코드 빈칸은 해시 시드 검사 없이 같은 엔진 두 번만(세트 메서드 빈칸 — 비교가 같은 엔진 안이라 순서 차이가 영향 없음), 슬라이드 오류 목록에 3-10 추가, 오류 항목에 `when`(그 코드 번호를 언급해도 달라지는 출력을 쓰지 않는 문항은 "(보충)" 검사 제외)
- 검증이 찾은 후보 규칙 버그 2건 수정: spacing이 `**`를 `* *`로 쪼갬, mirror가 파이썬 키워드 인자 `reverse=True`를 비교로 보고 뒤집음(`=` 비교는 SQL만)
- 콘텐츠 형식 검사: 인라인 코드 안의 `**`(거듭제곱 연산자)는 굵게 짝에서 빼고, 검증된 실행 결과 보기는 print가 만드는 두 칸 공백을 허용
- 보기 순서 테스트(choiceOrder.test.ts): 코드 블록 안 글자·단축키 번호와 겹치는 보기 때문에 위치 비교가 틀어져 코드 블록 뒤부터 찾고 한 글자 숫자 보기는 제외(화면 동작은 정상)
- 복수 선택 안내 문구: 데이터과학(0/1 채점)에서 "틀린 보기를 고르면 감점됩니다" 대신 "정답을 모두 고르고 틀린 보기는 하나도 고르지 않아야 정답(부분 점수 없음)" — 다른 과목 문구·렌더링은 그대로(렌더링 해시 586/586 같음)
