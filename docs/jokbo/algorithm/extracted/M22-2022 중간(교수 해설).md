## 1 (p.2) 정답 1
아래의 알고리즘은 유클리드의 최대 공약수를 계산하는 알고리즘이다. 이 알고리즘의 시간 복잡도는 어떻게 되나?
```
Euclid(a, b)
입력: 정수 a, b;  단, a≥b≥0
출력: 최대공약수(a, b)

1. If (b=0) return a
2. return Euclid(b, a mod b)
```
1) O(log(a))  2) O(log(b))  3) O(a)  4) O(b)  5) O(log(a mod b))
설명: 유클리드 알고리즘은 두 수 중 작은 수로 큰 수를 더 이상 나누어 지지 않을 때, 즉 나머지가 0이 될때 까지 계속 나누기와 나머지 계산을 반복한다. 이 반복에서 몫은 항상 1이 되고, 나머지가 b − 1이 되는 최악의 경우를 생각해 보자, 즉 a = b·1 + (b−1)이 반복되는 경우이다. 여기서, a와 나머지의 관계를 관찰해 보면, 나머지(b−1)는 a/2와 비슷한 값이라는 것을 알 수 있고, 이 경우의 점화식은 T(a) = T(a/2) + C에 근사하게 되어, O(loga)가 됨.

## 2 (p.3) 정답 5
아래의 코드는 하노이탑 알고리즘이다. a, b, c라는 세개의 기둥이 있고, 기둥 a에 있는 n개의 원반을 기둥 b로 옮기되, 한번에 하나씩만 옮길 수 있으며, 어떠한 경우이든 큰 원반이 작은 원반 위에 놓여서는 안된다는 조건을 만족해야 한다. 이를 푸는 알고리즘이 아래와 같을 때 이 알고리즘의 시간 복잡도는 어떻게 되나?
```
move(n, a, b, c)
{
    if( n > 0 ) {
        move(n-1, a, c, b);
        move(1, a, b, c);
        move(n-1, c, b, a);
    }
}
```
1) O(n)  2) O(log n)  3) O(n²)  4) O(n³)  5) O(2ⁿ)
설명: 이 코드의 점화식은 T(n) = T(n-1) + C + T(n-1) = 2T(n-1) + C, 반복 대입법을 적용하면, T(n) = 2ⁿ + … 그러므로, O(2ⁿ)

## 13 (p.15–16, 손글씨 14) 정답 44321 — 교수 표시 "문제 오류: 모두 정답으로 인정"
배열 A[1, …, 10]이 [12, 70, 50, 20, 55, 25, 40, 30, 65, 29] 로 되어 있을 경우, 아래의 그림은 select() 알고리즘을 이용하여 8번째 작은 수를 찾는 과정을 순서대로 나열한 것이다. 각 단계의 빈칸에 들어갈 수를 차례대로 입력하라. (숫자만 입력하고, 숫자사이에는 공백을 입력하지 마시오.)
```
[12, 70, 50, 20, 55, 25, 40, 30, 65, 29]
select(A, 1, 10, 8)
[12, 20, 25], 29, [70, 55, 50, 40, 30, 65]
select(A, 5, 10, __)
[55, 50, 40, 30], 65, [70]
select(A, 5, 8, __)
30, [55, 50, 40]
select(A, 6, 8, __)
40, [55, 50]

50, [55]

```
