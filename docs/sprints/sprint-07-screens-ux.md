# Sprint 7 — 화면 / UX 구현

## 목표

원본 §3(정보 구조)의 화면을 **과목 → 챕터** 흐름([`multi-subject-design.md`](../multi-subject-design.md) §4)으로 실제 데이터와 연결해 처음부터 끝까지(홈 → 과목 → 챕터 선택 → 퀴즈 → 결과 → 오답노트) 풀 수 있는 앱을 완성한다. 이 시점의 실제 콘텐츠는 OS뿐이지만, 모든 화면은 과목 레지스트리를 순회해서 만들어 데이터 통신 콘텐츠가 추가될 때 화면 코드를 고치지 않게 한다.

## 선행 조건

- Sprint 3(렌더러/채점기), 최소 Sprint 5(Ch02·Ch03 콘텐츠) 완료. Sprint 6 콘텐츠는 완료 전이어도 병행 가능.

## 작업 항목

### `/` 홈 (과목 선택)

- [ ] 과목 카드: 과목명, 대표 색, 챕터 수, 문제 수, 진행률, 정답률, ⭐ 문제 수 (문제 0개 과목은 "준비 중" 비활성 카드)
- [ ] "전체 오답노트", "전체 통계" 바로가기
- [ ] 테마 토글 배치 (헤더)

### `/s/[subject]` 과목 홈

- [ ] 챕터 카드: 챕터명, 문제 수, 진행률, 정답률, ⭐ 시험 포인트 문제 수 (원본 §3의 기존 홈 카드 항목)
- [ ] "이 과목 ⭐ 시험 포인트만 풀기" 바로가기
- [ ] "이 과목 오답노트" 바로가기 (`/review?subject={id}`)
- [ ] 헤더 브레드크럼 `홈 › 과목 › 챕터` + 과목 색 점(텍스트 병기)

### `/s/[subject]/chapter/[id]` 챕터 시작 화면

- [ ] 문제 유형 필터(복수 선택) — 문제 유형 레지스트리 기반, 그 챕터 데이터에 있는 유형만 표시
- [ ] ⭐ 시험 포인트만 필터
- [ ] 문제 수 선택(10/20/30/전체)
- [ ] 섞기 옵션
- [ ] 토픽(세부 주제) 필터
- [ ] "시작" → `/quiz?subject=…&chapter=…&…`로 필터 조건 전달, id 목록 세션은 `examapp:session`

### `/quiz` 문제 풀이 화면

- [ ] 상단 진행바, 문제 번호, 유형 뱃지, ⭐ 뱃지, 북마크 버튼
- [ ] **즉시 채점 모드**: 제출 즉시 정답/해설 표시 — 결과 맨 위 "✓ 정답 / ✗ 오답" 배너(완전히 맞을 때만 정답, 부분 점수는 아래 보조 표시, Sprint 3의 `QuestionRenderer` 재사용)
- [ ] **시험 모드**: 끝까지 풀고 한 번에 채점, 선택적 타이머
- [ ] 모드/타이머 설정은 챕터 시작 화면 또는 퀴즈 진입 시 선택
- [ ] 문제 간 이동(←/→), 제출(Enter), 선택지(1~5) 키보드 단축키 연결
- [ ] 각 유형의 정답/오답 비교 UI 표시 (Sprint 3 컴포넌트 재사용)

### `/result` 결과 화면

- [ ] 총점(정답 문제 수 = 완전히 맞은 문제 수), 유형별/토픽별 정답률 — 부분 점수는 정답으로 세지 않는다
- [ ] 틀린 문제 목록 (부분 점수만 받은 문제도 포함) — 풀이 결과는 `recordAttempt`로 기록
- [ ] "틀린 문제만 다시 풀기" → `/quiz`로 재진입

### `/review` 오답노트 + 북마크

- [ ] 과목 탭 `[전체] [과목별…]` (기본: 진입한 과목, 홈에서 오면 전체) + 챕터별 필터. `전체`는 과목별 그룹 + 과목 뱃지
- [ ] 오답노트/북마크 목록, 다시 풀기 진입점

### 공통

- [ ] localStorage 연동: 과목별 키(`examapp:{subject}:progress|wrong|bookmarks`, `lib/storage/keys.ts`)로 진행률/정답률/오답/북마크, 전역 `examapp:settings` — 모두 `safeStorage` 경유, `useEffect` 내부에서만 접근. Sprint 2의 마이그레이션 실행 이후에 읽기
- [ ] `/quiz`·`/result`: 여러 과목이 섞인 세션(전체 오답 다시 풀기)에서도 동작, 결과에 과목별 소계
- [ ] 모바일 반응형 점검: 카드 레이아웃, 퀴즈 화면 1열 전환, `order`/`trace` 모바일 입력 대체 동작 확인
- [ ] 각 문제 해설에 출처 슬라이드 위치(`slideRef`)와 핵심 개념 한 줄 요약 표시

## 완료 기준 (DoD)

- 홈에서 과목 → 챕터 선택 → 필터 설정 → 즉시채점/시험 모드 각각으로 퀴즈 완료 → 결과 확인 → 오답노트에서 재응시까지 전체 플로우가 끊김 없이 동작
- localStorage를 비활성화한 브라우저 환경(혹은 모킹)에서도 앱이 에러 없이 동작 (요구사항 §1 "저장소가 막혀 있어도 정상 동작")
- 모바일 뷰포트(375px 기준)에서 모든 화면과 모든 문제 유형이 조작 가능
