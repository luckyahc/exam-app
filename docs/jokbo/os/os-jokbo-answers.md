### CH02-10. `os-ch02-jokbo-010`
- 출처: 2022 중간 8번 · 근거 슬라이드: Ch02 p.21 · 하나 고르기

사용자 프로그램 실행에 6초, CPU 스위칭에 0.3초, I/O스위칭에 0.7초, 그리고 CPU Idle에 3초가 소요되었다. 이 경우 CPU 이용률은 얼마인가?

① **0.6** ✅  
② 0.3  
③ 0.7  
④ 0.8  
⑤ 0.5  

**정답: ①**

> 해설: 교수님 채점 기준(2022 시험): 스위칭 시간을 뺀 유효 실행 시간 기준 6/10 = 0.6. 바쁜 시간 전체로 계산하면 (6+0.3+0.7)/10 = 0.7. p.21의 유효 CPU 이용률(= 유효 프로그램 실행시간 / 총 경과시간) 계산이며, 슬라이드 예(사용자 7초 + CPU 스위칭 0.6초 + I/O 스위칭 0.4초 + 휴식 2초 → 7/10 = 0.7)와 Ch02 ⭐ 시간 계산 예제(6 / (6 + 0.5 + 0.5 + 3) = 0.6)와 같은 방식이다. 이론적으로 p.21의 CPU 이용률 정의(CPU가 바쁜(non-idle) 시간 / 전체 시간)는 스위칭 시간도 바쁜 시간에 넣는다. 원문 오타: '소요되었었다' → '소요되었다'.
