# 데이터과학 기말 출제 형식 (족보: source/data-science/jokbo, e-Class 중간시험 화면 38장)

- 유형: 코드·SQL 빈칸(`#1`~`#5` 칸을 순서대로 채움, 문항의 중심) > 4지 객관식(실행 결과 고르기·"틀린 것을 고르시오") > 단답(기호·명령어 한 단어) > 짝 짓기(함수 ↔ 그래프 종류).
- 지문 말투: "~하는 명령을 완성하시오", "빈 칸을 채워주세요", "다음 코드의 실행 결과를 선택하세요", "~으로 틀린 것을 고르시오".
- 조건은 지문 다음 줄 괄호: "(단, '학생' 테이블은 … 컬럼을 가지고 있다)", "(단, 답안 작성시 빈칸은 추가하지 말아주세요)".
- 객관식 보기는 4개. 실행 결과 보기는 여러 줄 출력 그대로.
- 대괄호·그림 표기 없음 — 코드는 지문 아래 그대로, 표는 쓰지 않는다.
- 이 앱에서: 코드 빈칸 = code-blank(코드 문제의 60% 이상), 실행 결과 = mcq + verify output(30% 이하), 복수 선택 8% 이상, mcq 30% 이하(ratio.test.ts).
- 근거는 강의자료(Lec7 s.26~59, Lec8)뿐, 강의자료에 없는 설명은 "(보충)". ⭐ 없음. 해설은 "s.번호:"로 시작.
