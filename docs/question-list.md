# 풀이 상태별 문제 보기 (전 과목)

과목마다 `/s/{과목}/questions`에서 문제를 풀이 상태별로 모아 본다. 코드: `lib/quiz/status.ts`(상태 판정), `lib/quiz/questionList.ts`(필터·탭·세션), `components/questions/QuestionList.tsx`(화면). 테스트: `lib/quiz/questionList.test.ts`.

## 상태 정의 (기존 판정 규칙을 그대로 따름 — `lib/storage/records.ts`)

| 상태 | 정의 |
|---|---|
| 안 푼 문제 | 그 문제의 풀이 기록이 없음. 시험 모드에서 답하지 않은 문제는 기존 규칙대로 기록하지 않으므로 여기에 들어간다 |
| 맞힌 문제 | 마지막 풀이가 완전히 맞음(점수 1 — 부분 점수는 오답이라는 기존 규칙과 같음) |
| 틀린 문제 | 마지막 풀이가 오답(예전에 맞혔어도 마지막이 틀리면 틀린 문제) |
| 북마크 | 상태와 별도 탭(북마크한 문제) |

- 기존 규칙과 충돌 없음. 다만 마지막 점수가 저장되지 않은 옛 기록(v1에서 옮겨 온 기록, `lastScore: null`)은 마지막 결과를 알 수 없어, 오답노트가 미해결이면 틀린 문제, 아니면 정답 횟수가 있으면 맞힌 문제로 본다
- 기록은 이 기기·브라우저(localStorage)에 있는 것만 본다

## 화면

- 탭: 전체 / 안 푼 문제 / 맞힌 문제 / 틀린 문제 / 북마크 — 탭마다 개수(필터 적용 후). 키보드: 탭에서 ←/→, 줄은 Tab·Enter
- 필터: 챕터, 유형, 토픽(챕터를 고르면 그 챕터 토픽만), ⭐ — OS는 전체 ⭐ / 교수님 필기만(examBasis handwritten) / 시험 힌트만(hintIds 있음) 중 선택, 데이터 통신은 "시험 포인트만"(인쇄 강조 하나뿐), 데이터과학은 숨김(⭐ 없음). 기준은 `lib/quiz/starBasis.ts`
- 각 줄: 문제 앞부분, 챕터, 유형, ⭐, 마지막 결과(✓ 맞음 / ✗ 틀림 / – 미풀이), 시도 횟수, 북마크
- 줄을 누르면: **바로 풀기**(그 문제 하나로 즉시 채점 퀴즈) / **정답·해설 보기**(정답 키로 채점한 화면만 보여 줌 — 풀이 기록에 넣지 않는다)
- **이 목록으로 풀기**: 지금 탭·필터 결과로 퀴즈 시작(섞기, 문제 수 10·20·30·전체)
- 한 번에 100줄씩 그리고 "더 보기"로 늘린다(과목당 수백 문항)
- 챕터 시작 화면의 ⭐ 옵션도 같은 기준(근거가 둘인 챕터만 근거별 선택, 퀴즈 주소 `star=1|handwritten|hint`). 통계의 ⭐ 달성도는 OS에서 "필기 x/y · 힌트 a/b"를 함께 보여 준다
- 챕터 시작 화면에 "풀이 상태" 옵션(전체 / 안 푼 문제만 / 틀린 문제만 / 맞힌 문제만 — 개수 표시), 퀴즈 주소 `status=` 파라미터
- 전체 오답노트(`/review`) 위에 과목별 문제 목록 링크. 기존 오답노트·통계 기능은 그대로

## 생성 문제("비슷한 문제")

**목록에서 제외**한다. 목록은 챕터 데이터의 문제(정적 문항 + 고정 seed 생성기 문항)만 보여 주고, "비슷한 문제"로 새로 만든 문제(seed가 다른 생성기 문제)는 id가 달라 기록도 원래 문제와 섞이지 않는다. 그런 문제는 오답노트에서 다시 풀 수 있다.
