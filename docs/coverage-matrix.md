# 커버리지 매트릭스

`source-diff.md`로 확정된 슬라이드 페이지 매핑을 바탕으로, §7의 소주제(⭐ 포함)를 행으로, 문제 유형 10종 + 슬라이드 페이지를 열로 정리한 매트릭스다. **목표문항수** 열은 챕터별 최소 문항 수(Ch02 50 / Ch03 80 / Ch07 80 / Ch08 120)와 ⭐ 주제당 6~10문항 목표를 반영해 역산한 값이며, 콘텐츠 제작 스프린트(5·6)에서 실제 작성한 문항 수를 **실제** 열에 기록해 진행률을 추적한다. ✓ 표시는 "이 소주제에 적합한 문제 유형" 권장값이고, 실제 작성 시 §8의 전체 유형 비율 가이드를 벗어나지 않는 범위에서 조정 가능하다.

범례: mcq=객관식단일 / multi=복수선택 / ox=OX / blank=빈칸 / order=순서배치 / match=짝짓기 / classify=분류 / calc=계산 / trace=표채우기 / graph=그래프고르기


과목별로 나뉜다: 과목 1 운영체제(os), 과목 2 데이터 통신(data-comm). 두 과목 모두 같은 기준(원본 §8: ⭐ 주제당 6~10문항, 유형 혼합, 모든 소주제 커버, 중복 금지)을 쓴다.

## 과목 2 — 데이터 통신 (data-comm)

근거: [`dc-source-analysis.md`](./dc-source-analysis.md) — `source/data-communication/` PDF 2개(Ch01 개요 44장, Ch02 물리 계층 101장) 전수 분석. `slideRef`는 인쇄된 슬라이드 번호(`s.N`).

### 목표 문항 수 산정 규칙 (OS와 같은 기준)

- **⭐ 소주제**: 6~10문항(기본 8), 유형 혼합. 데이터 통신의 ⭐는 3개이고 `examBasis`는 **모두 `printed-emphasis`**(표에서 `⭐ P`)다 — 교수님 필기가 아니라 슬라이드 본문에 인쇄된 "very important". 근거 구분: 전송률 한계·Nyquist = 인쇄 강조 직접(s.33), 대역폭-지연 곱 = 인쇄 강조 직접(s.48), Shannon·두 한계 = s.33 인쇄 강조의 범위 확장(s.36~40에는 강조 문구 없음). s.41의 "important"(very 없음)는 검토했으나 ⭐ 제외(`dc-source-analysis.md` §2-2). 데이터 통신은 필기본이 없다(사용자 확인, 2026-10-04). OS의 ⭐는 모두 `handwritten`(교수님 필기) 근거다.
- **일반 소주제**: 2~4문항(OS 일반 소주제 분포와 동일). 그림·계산이 있는 소주제는 4, 정의 한두 개뿐인 소주제는 2.
- **챕터 최소 문항 수** = 소주제 목표 합계로 **확정**(사용자 확인, 2026-10-04): Ch01 ≥ 57, Ch02 ≥ 106.
- **문항 수 판정 기준(2026-10-05 사용자 승인)**: 데이터 통신은 챕터 파일에 고정 seed로 넣은 생성기 문항(`{generator, params, seed}`로 저장, id `…-gen-{이름}-{seed}`)을 **최소 문항 수에 포함**해 판정한다 — Ch02 = 정적 90 + 고정 seed 생성기 22 = 112 ≥ 106(정적만으로는 90 < 106). Ch01은 생성기 문항이 없다(정적 58 ≥ 57).
- **OS와의 차이**: OS 챕터도 고정 seed 생성기 문항을 챕터 파일에 넣고 '실제' 합계에 포함해 적었지만(Ch07 정적 82 + 생성기 7, Ch08 정적 134 + 생성기 4), **정적 문항만으로도 최소 문항 수를 넘는다**(Ch07 82 ≥ 80, Ch08 134 ≥ 120). 데이터 통신 Ch02는 생성기 문항을 포함해야 최소 문항 수를 넘는다.
- **유형 비율**: 원본 §8 비율을 그대로 기준으로 한다(코드 유형 없음). Ch01은 계산 공식이 없어 `calc` 0, 대신 `match`·`classify`·`order`·`graph` 비중이 높다. Ch02는 생성기 문제(`calc`·`trace`)가 §8 비율(5%·3%)보다 많다 — 공식이 많은 장이라 의도된 편차이며, 생성기 문제는 seed로 무한 변형되므로 정적 문항 수에서는 비율을 지킨다.
- 출제 제외: CDMA(3장 예고, s.83), 핸드셰이크·헤더 필드 구조(슬라이드에 없음), 메시 링크 수 공식·델타 변조 비트열 생성(확인 필요 3·8).
