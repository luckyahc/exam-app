## 2. 작성 규칙

- id `algorithm-{chapter}-mock{세트}-{NNN}`, NNN = 세트 안 순서(001~030, 장 순서). 세트로 풀면 이 순서 그대로 낸다.
- `basedOn`이 있어 "족보관련" 분류·일반 풀이에도 보인다. 뱃지는 "족보관련1"·"족보관련2".
- 같은 유형의 족보가 없으면 형식을 따른 족보 id를 `basedOn`에 넣고 해설 첫 줄에 "형식 참고: id".
- 해설 = (형식 참고) + 풀이 + 근거(강의자료 쪽) + 함정 1줄. 강의자료에 없는 내용은 "(보충)" — 하노이탑(족보 코드), 계수 정렬 범위가 클 때의 비용, 역순 입력 = 삽입 정렬 최악.
- 족보 기준과 이론이 다른 지점(sorting-jokbo-011: 정렬된 입력에서 힙 정렬 O(n))은 세트 문항에서 정답이 갈리지 않게 피했다(족보관련1 017은 Θ(n²)인 것을 물어 힙 정렬은 어느 기준으로도 오답).
