# Sprint 8 — 학습 기능 고도화

## 목표

원본 §9(학습 기능)의 나머지 요구사항을 완성한다. Sprint 7에서 기본 오답노트/북마크는 이미 동작하므로, 여기서는 집계·재생성·데이터 관리 기능에 집중한다.

## 선행 조건

- Sprint 6(전체 콘텐츠), Sprint 7(화면/UX) 완료

## 작업 항목

- [ ] 오답노트 자동 누적 고도화: 틀린 문제 id + 시도 횟수 기록, 맞출 때까지 추적 — "틀림" = 완전히 맞지 않음(부분 점수 포함), `recordAttempt` 사용
- [ ] `/stats?subject=…` 대시보드: 과목 탭 `[전체] [과목별…]`, 과목 → 챕터 → 토픽 단계로 진행률/정답률 (과목별 기록에서 `summarize`로 계산, 완전히 맞음 기준 — 부분 점수 제외)
- [ ] ⭐ 시험 포인트 달성도 지표 (예: ⭐ 문제 중 완전히 맞춘 비율)
- [ ] "비슷한 문제 새로 생성" 버튼: 생성기 기반 문제(`generator` 필드 존재)에서만 노출, 과목 레지스트리의 `generators[q.generator.name]`으로 seed를 바꿔 재호출 (과목 무관 공용 코드)
- [ ] 데이터 초기화 기능: 확인 다이얼로그 → 범위 선택(과목별 / 전체). `examapp:` 키만 삭제, 테마는 유지 여부 선택
- [ ] 학습 기록 JSON 내보내기: `version` 필드가 있는 v2 형식(`app`, `version`, `exportedAt`, `settings`, `subjects.{id}`) — 전체 또는 과목 선택 ([`multi-subject-design.md`](../multi-subject-design.md) §5-4)
- [ ] 학습 기록 JSON 가져오기: 버전 판별(숫자 / 없음+v1 형태 / 그 외 거부 / 미래 버전 거부) → **구버전(v1) 파일은 Sprint 2의 `upgradeV1toV2`로 변환** → 손으로 쓴 타입 가드 검증(5MB 상한) → 과목별 덮어쓰기/합치기 선택 후 반영. 모르는 과목은 건너뛰고 알림, 잘못된 형식은 에러 메시지만 (앱 크래시 방지)
- [ ] `backup.test.ts`: v2 왕복, v1 파일, 버전 없는 임의 JSON, 미래 버전, 깨진 JSON, 모르는 과목

## 완료 기준 (DoD)

- 오답노트에서 동일 문제를 여러 번 틀렸을 때 시도 횟수가 정확히 누적됨
- 대시보드 수치가 실제 풀이 결과와 일치 (수동 시나리오 2~3개로 검증)
- 생성기 기반 문제에서 "비슷한 문제 생성" 클릭 시 매번 다른 파라미터의 유효한 문제가 나오고 정답이 항상 올바름 (시뮬레이터 재사용 확인)
- 내보낸 JSON을 초기화 후 다시 가져오면 이전 학습 상태가 그대로 복원됨 (과목별/전체 모두)
- v1 형식 fixture 파일을 가져오면 OS 기록으로 복원됨
- 잘못된 JSON 파일을 가져와도 앱이 죽지 않고 에러 메시지만 표시
