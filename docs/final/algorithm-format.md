# 알고리즘 기말 출제 형식 (기준: 이번 학기 중간고사 `source/algorithm/jokbo/알고리즘_중간시험_25문제.docx`, 25문항 × 10점)

- 유형 비율: 5지 단일 선택 14 (56%, 예/아니오 1 포함) · 단답 9 (36%, 숫자 1개 3 · 숫자열/기호열 6) · 복수 선택 "모두 고르시오" 2 (8%). OX·짝 짓기·코드 빈칸 없음.
- 내용: 데이터로 직접 계산·추적 13(DP 표 칸, 힙 교환 순서, 기수 정렬 위치, select의 k) · 코드·점화식 → 복잡도 8 · 개념 4(Ω/Θ 판정, 포함 관계, O(n) 정렬).
- 지문 말투: "~로 알맞은 것은?", "빈칸 (A)~(F)를 구하시오", "순서대로 적으시오", "틀린 것을 모두 고르시오", "가장 정밀한 점근적 상한은?".
- 보기: 단일 선택 5개(1)~5)), 오름차순 수치·복잡도 나열 또는 "(A) 28, (B) 37, (C) 50, O(n)"처럼 여러 값 + 복잡도를 한 보기에 묶음.
- 단답: 여러 값을 공백 없이 이어 쓰기(20112, EGCFBD, 42211, 7372), 표 칸은 (A)~(F) 기호로 지정.
- 표기: 배열·표 인덱스는 1부터(DP[1..n], 힙 2i·2i+1), 의사코드는 C 스타일 중괄호 `move(n, a, b, c) { … }`, 표·행렬은 글자 표.
- 난이도: 손계산 2~5분 분량(n = 4~10), 계산기 불필요. 한 문항 안에서 과정 값 + 최종값 + 복잡도를 함께 묻는다.
- 이 앱에서: mcq(보기 5) ≈ 50% · blank(숫자열·기호열·여러 칸) ≈ 40% · multi(정답 2개 이상) ≈ 10%. 동점 규칙(사전순·작은 번호)과 인접 리스트 순서는 지문에 적어 정답을 하나로 고정한다.

## 기존 족보(docs/jokbo/algorithm/pattern-analysis.md)와 다른 점 — 이번 학기 경향

1. 개념형 예/아니오·상한/하한 판정(P1류)이 줄고(1문항), 표·배열을 직접 채우는 추적·계산형이 대부분이다.
2. 답을 한 칸에 이어 쓰는 단답(숫자열·알파벳열)과 "(A)·(B)·(C) + 복잡도" 묶음 보기가 새로 많아졌다.
3. 문제당 계산량이 커졌다(한 문항에서 표의 칸 3~6개) — 기말 생성 문항도 과정 값 여러 개를 함께 묻는다.
