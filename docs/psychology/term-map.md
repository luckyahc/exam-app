# 용어 대응표 — 요약 노트 → 교재

기준: `docs/psychology/summary-notes-textbook.pdf`(요약 노트 1~8장을 교재 용어로 바꾼 판, 로컬 전용) 맨 뒤 "용어 대응표". 문항의 용어 표기는 **교재 표기**를 쓰고, 요약 노트 표기는 해설 괄호와 단답형 인정 답안에만 둔다. 쪽 번호는 원본 `summary-notes.pdf` 하단 쪽 번호를 그대로 쓴다.

## 교재 판 PDF의 치환 오류 (문항에서는 따르지 않음)

- "내분비계"가 "내분도약대"로 바뀌어 있다(비계 → 도약대 치환이 단어 안까지 들어감, 교재 판 p.6~7의 절 제목·본문). 문항은 **내분비계**를 쓴다.
- 조사가 맞지 않는 곳("스키마을", "태아 알코올 증후군라고", "부분(간헐적) 강화계획는")은 표기만 따르고 조사는 고쳐 쓴다.
